# BRNT OUT // Knowledge Web Data

This repository is the data layer for the BRNT OUT Knowledge Web —
an open, sourced, and continuously expanding research tool mapping
extraction, resistance, and power across history.

## Structure
- /data — all node data files (eras, events, people, themes, industries)
- /schema — the node schema template every entry must follow
- /sources — the source registry with credibility metadata
- /CHANGELOG.md — log of all significant data updates

## Contributing
Contributions go through review before being added to the live dataset.
